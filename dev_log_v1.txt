# Investment Panel - Dev Log v1

## 项目定位

一个 thesis-centric 的个人投资管理工具。

**核心问题**：信息按日期记录，但思维按 thesis 流动，导致同一主题的信息散落各处，待办沉没，复盘困难。

**Panel 负责的阶段**：从"这个想法值得认真对待"到"这个 thesis 彻底关闭"之间的生命周期管理。

**Panel 不负责**：
- 信息输入/发现（你自己刷消息）
- Research 过程（在 LLM 里进行）
- 交易执行（券商 app）
- 精确仓位数据（券商 app）
- 行情数据（券商/行情软件）

## 数据结构

### Thesis（主题）
Thesis 
├── 名称 
├── 状态：观望 / 研究中 / 建仓中 / 持有 / 止盈中 / 已关闭 
├── Conviction：↑ / ↗ / → / ↘ / ↓ 
├── 一句话判断 
└── 关联标的（多个）

### 标的（Instrument）
标的 
├── 名称 
├── 主要归属 Thesis（仓位计算归这里） 
├── 关联 Thesis（可多个，双链） 
├── 类别：进攻 / 防守 
├── 仓位级别：○ / ◔ / ◑ / ◕（无 / 轻 / 中 / 重） 
├── 状态：待研究 / 观望 / 持有 / 止盈中 / 已清仓 
└── 仓位比例：%

### 记录（统一格式）
记录 
├── 时间戳 
├── 类型：观点 / 操作 / 消息 
├── 关联：Thesis 和/或 标的（可多选，双链）
├── 方向：+ / - / ?（观点和消息用） 
├── 内容：自由文本 
└── 操作详情（仅操作类型） 
├── 操作类型：买入 / 卖出 / 转换 
├── 数量 
└── 当日涨幅

### 待办
待办 
├── 内容 
├── 类型：待研究 / 待决策 
├── 关联：Thesis 或 标的（可选） 
├── 创建日期 
└── 完成状态

## Launchpad 结构

### 顶部：Thesis 卡片
- 按主题分组显示
- 每张卡片：名称 | 状态符号 | conviction 箭头 | 一句话判断
- 卡片内显示关联标的摘要：名称 + 仓位符号 + 状态符号
- 点击卡片进入 Thesis 详情页
- 点击标的进入标的详情页（可看到所有关联 Thesis，双链）

### 中部左：交互式饼图
- 直接在饼上拖动边界线调整比例（像拨钟表指针）
- Snap to 5% 刻度
- 调整时自动和现金池对换
- 三个视图可切换：
  - 类别视图（进攻/防守/现金）- 只读
  - Thesis 视图 - 只读
  - 标的视图 - 可编辑
- 数据是同一份，标的调整后上层自动聚合

### 中部右：待办/待研究
- 列表显示未完成的待办
- 显示：类型图标 + 内容 + 关联 + 创建日期
- 可快速添加

### 底部：近期操作
- 时间线显示最近的操作记录
- 显示：日期 | 标的 | 操作类型 | 数量 | 当日涨幅
- 右上角 [+] 按钮触发快速输入

### 快速输入弹窗
- 先选类型：操作 / 观点 / 消息
- 根据类型显示不同字段
- 操作：标的、买/卖/转换、数量、当日涨幅
- 观点：关联（Thesis/标的）、+/-/?、内容
- 消息：+/-/?、内容、关联（可选，可多选）

## 符号系统

### Thesis 状态
- 🟢 活跃（建仓中/持有/止盈中）
- 🟡 观察（观望/研究中）
- ⚪ 已关闭

### Conviction
- ↑ 强烈看多
- ↗ 偏多
- → 中性
- ↘ 偏空
- ↓ 强烈看空

### 仓位级别
- ○ 无仓位
- ◔ 轻仓
- ◑ 中仓
- ◕ 重仓

### 标的状态
- 🔍 或 ? 待研究
- ─ 持有不动
- ↓ 或 ⤵️ 止盈中
- ✓ 已清仓

### 消息/观点方向
- + 利多
- - 利空
- ? 不确定/待观察

## 详情页

### Thesis 详情页
- 核心逻辑
- Conviction + 状态
- 触发条件
- 关联标的列表（各自状态）
- 完整时间线（所有关联记录）

### 标的详情页
- 当前状态 + 仓位
- 所有关联 Thesis（双链，可跳转）
- 完整时间线（所有关联记录）

## 设计原则

1. **Thesis 为核心组织单位**，不是日期，不是标的
2. **双链关联**：标的可属于多个 Thesis，消息可关联多处，但仓位只算一次（归主要 Thesis）
3. **输入轻量**：结构化字段用选择，自由文本用于保留上下文
4. **符号优先**：状态、方向、仓位用符号，一眼可扫
5. **两种节奏共存**：日常快速记录 + 定期收网归档
